# Sophos Fusion EDR and XDR Queries

## Purpose
  This repository will host EDR (Live Discover) queries migrated from the "central_xdr_queries" repo and XDR (Data Lake) queries for Sophos Fusion. The queries listed here are provided "AS IS" and are not supported through the Sophos Support Team. For support or assistance in building custom searches, the Professional Services team can build a statement of work (SOW) after scoping the objective an organization is looking to achieve. 

### Resources

1. Review available [Integrations](https://docs.sophos.com/central/customer/help/en-us/ManageYourProducts/ThreatAnalysisCenter/Integrations/OverviewAddIntegrations/index.html) within the Marketplace to ingest all security tools used in the organization
2. Understand the [EDR and XDR](https://docs.sophos.com/central/customer/help/en-us/ManageYourProducts/XDR/index.html) differences
3. Consider using the [AI Assistant tools](https://docs.sophos.com/central/customer/help/en-us/AI/index.html) for helping write queries and performing SecOp tasks
